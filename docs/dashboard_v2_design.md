## 一、技术选型决策

### 结论：继续 Streamlit，不升级

| 维度 | Streamlit | Dash | Gradio | 自建React |
|------|-----------|------|--------|-----------|
| 开发速度 | ★★★★★ | ★★★ | ★★★★ | ★ |
| 图表能力 | ★★★★ (Plotly) | ★★★★★ | ★★★ | ★★★★★ |
| 实时刷新 | ★★★★ (st.fragment) | ★★★★★ (callback) | ★★ | ★★★★★ |
| 学习成本 | ★★★★★ | ★★★ | ★★★★ | ★ |
| 适合场景 | 数据仪表盘 | 企业级应用 | ML演示 | 产品级 |
| 与现有代码兼容 | 100% | 需重写 | 需重写 | 需重写 |

**理由**：
1. 现有 `dashboard/app.py` 已基于 Streamlit，迁移成本为零
2. Streamlit 原生支持 Plotly（金融图表标准库）、st.dataframe（高性能表格）、st.metric（指标卡）
3. 本系统是**个人量化系统**，不需要多用户/权限/部署等企业级特性
4. `st.fragment` (Streamlit 1.33+) 已支持局部刷新，满足准实时需求
5. 关键增强：引入 **Plotly** 替代原生图表（热力图/雷达图/桑基图/3D曲面）

### 依赖新增

```
plotly>=5.18        # 高级图表（热力图/雷达/桑基/等高线）
streamlit-aggrid    # 可交互表格（排序/过滤/选择）
streamlit-extras    # 增强组件（卡片/标签/动画）
```

## 六、关键设计原则

1. **数据加载层统一**：所有页面通过 `dashboard/data_loader.py` 加载数据，内置 `@st.cache_data(ttl=300)` 缓存，避免重复IO
2. **优雅降级**：数据缺失时显示空状态提示而非报错，如"暂无IC历史数据，运行因子验证后自动生成"
3. **Plotly统一主题**：深色背景 + 金融配色（红涨绿跌），所有图表风格一致
4. **组件化**：因子图表、KPI卡片等高频组件抽取到 `components/`，避免重复代码
5. **无侵入**：Dashboard 只读取数据文件/SQLite，不修改任何业务逻辑代码
