# 第4篇：量化策略核心概念

> 最后同步日期: 2026-07-28 | 对应代码版本: 操盘密码 V9.0（文档版本 V3.2）

> 量化交易是用数学模型和计算机程序替代人工判断进行投资决策的方法。
> 本篇涵盖多因子模型、回测方法论、绩效指标、Kelly公式、风险平价和信号衰减等核心概念。

> **新手阅读建议**：通俗来说，量化交易就是"用规则代替情绪"。
> 打个比方：普通散户炒股像"凭感觉做菜"（今天成明天败），量化交易像"按精确食谱做菜"（每次放多少盐、炒几分钟都写死）。
> 好处是：不会因为贪婪追高、不会因为恐惧割在最低点——因为一切按规则来。
> 本系统就是一个"量化食谱"：什么时候买、买多少、什么时候卖，全部由程序计算决定。
>
> 本篇涉及的系统模块：
> - 多因子评分 → `strategy/multi_factor.py`（四维评分体系）
> - 回测验证 → `backtest/engine.py` + `backtest/walk_forward.py`
> - 绩效指标 → `backtest/metrics.py`（夏普/回撤/胜率）
> - 仓位管理 → `position/kelly.py` + `position/risk_parity.py`
> - 信号衰减 → `strategy/signal_decay.py`
> - 共识评分 → `strategy/consensus.py`

## 4.1 多因子模型

### 什么是多因子模型

> **打个比方**：多因子模型就像"高考总分制"。高考不是只看一科，而是语文+数学+英语+综合按权重加总。
> 选股也一样：不能只看"涨得好不好"（技术面），还要看"资金在不在买"（资金面）、"公司赚钱不赚钱"（基本面）。
> 本系统给每只股票打一个0-100分的"综合成绩"，70分以上才推荐买入。

多因子模型是一种将多个"因子"（影响股价的因素）综合评分，从而对股票进行排名和筛选的方法。

**类比理解**：就像高考有多个科目（语文、数学、英语、理综），每个科目按权重加权计算总分，然后按总分排名录取。

### 本系统的四维因子体系

本系统（`multi_factor.py`）采用四维评分体系，综合评分范围 0-100 分：

| 维度 | 权重 | 核心因子 | 评分逻辑 |
|------|------|---------|---------|
| 技术面 | **30%** | 趋势级别、DK信号、乖离率、筹码集中度 | 5级趋势=100分，D点加分，超买减分 |
| 资金面 | **30%** | 主力连续流入天数、资金模式、顶底背离 | 温和建仓+15分，对倒骗线-20分 |
| 动量面 | **20%** | 5日/20日涨幅、相对强度、量能配合 | 放量上涨+10分，放量下跌-10分 |
| 基本面 | **20%** | ROE、营收增速、PEG | ROE>15% +20分，ROE<5% -10分 |

### 综合评分计算

$$综合分 = 技术面 \times 0.30 + 资金面 \times 0.30 + 动量面 \times 0.20 + 基本面 \times 0.20$$

**计算示例**：某股票各维度评分为：技术面 80，资金面 70，动量面 65，基本面 55

$$综合分 = 80 \times 0.30 + 70 \times 0.30 + 65 \times 0.20 + 55 \times 0.20 = 24 + 21 + 13 + 11 = 69分$$

### 推荐分级

| 综合分 | 推荐等级 | 操作建议 |
|--------|---------|---------|
| ≥ 70 | 强烈推荐 | 可以建仓/加仓 |
| 55-69 | 关注 | 纳入观察池 |
| 40-54 | 观望 | 暂不参与 |
| < 40 | 回避 | 远离或清仓 |

> **本系统应用**
>
> `MultiFactorScorer` 类（`multi_factor.py`）的工作流程：
> 1. 接收 `CaopanEngine.analyze()` 的结果列表
> 2. 对每只股票计算四维评分
> 3. 按综合分排序，标记推荐等级
> 4. 输出排名表（含各维度子分）
>
> 技术面评分中，趋势级别占技术面的60%权重（5级=100，4级=75，3级=50，2级=25，1级=0）。
> 资金面评分融合了真实资金数据（权重40%），避免仅靠量价推算的误差。

## 4.2 回测方法论

### 什么是回测

> **打个比方**：回测就像"用过去10年的高考真题测试一套复习方法"。
> 如果你发明的复习方法在过去10年都能考650分，那它未来大概率也不错。
> 但注意：如果方法只是"背下了过去10年的答案"（过拟合），那遇到新题就废了。

回测是用历史数据模拟策略的交易表现，评估策略是否可行。

**类比理解**：就像用过去10年的高考题测试一套复习方法，看能考多少分。

### 回测中的常见陷阱

#### 1. 前视偏差（Look-Ahead Bias）

**定义**：在回测中使用了策略在当时不可能获得的未来数据。

> **示例**：在2024年1月的决策中使用了2024年6月才公布的财报数据。
> 这会导致回测结果看起来很好，但实盘中无法复现。

**防范方法**：确保策略在每个时间点只使用该时间点之前已公开的数据。

#### 2. 过拟合（Overfitting）

**定义**：策略参数过度适应历史数据，在样本外表现很差。

> **示例**：通过网格搜索找到 EMA(11.5, 37.2) 在2023年表现最优。
> 但这个精确参数在2024年可能完全失效，因为11.5和37.2只是恰好适配了那段行情。

**防范方法**：
- 使用整数参数（如EMA13、EMA34），而非小数
- 相邻参数（如EMA12、EMA13、EMA14）表现应相近（鲁棒性检验）
- 样本内外验证（70%训练 + 30%验证）

#### 3. Walk-Forward分析（滚动前推验证）

**定义**：将数据分为多个窗口，每个窗口内用前段数据优化参数，后段数据验证。

```
|--- 训练 ---|--- 验证 ---|
             |--- 训练 ---|--- 验证 ---|
                          |--- 训练 ---|--- 验证 ---|
```

> **示例**：用2022年数据优化参数，在2023年Q1验证；
> 然后用2022+2023Q1优化，在2023Q2验证；依此类推。
> 所有验证段拼接起来的表现才是策略的真实能力。

> **本系统应用**
>
> `CaopanEngine` 提供了两种回测验证方法：
> 1. **样本内外验证**（`train_test_split_backtest()`）：70%训练 + 30%验证，
>    验证集收益 ≥ 训练集收益 × 80% 判定为鲁棒
> 2. **参数优化**（`optimize_params()`）：网格搜索所有参数组合，
>    按夏普比率排序，要求总交易 ≥ 3次才纳入评估
>
> 回测中还考虑了真实交易成本：佣金（万3）、印花税（千1）、滑点（0.1%）。

## 4.3 绩效指标

> **打个比方**：绩效指标就像"体检报告"。你去医院体检，医生不会只看一个指标，
> 而是看血压、血糖、心率等多项综合判断。策略也一样：
> 夏普比率="性价比"（赚的钱值不值得冒的险），最大回撤="最惨的时候亏多少"，胜率="十次能赢几次"。

### 夏普比率（Sharpe Ratio）

**定义**：每承受一单位风险所获得的超额收益。

$$Sharpe = \frac{R_p - R_f}{\sigma_p} \times \sqrt{252}$$

- \(R_p\)：策略日均收益率
- \(R_f\)：无风险利率（本系统默认3%/年）
- \(\sigma_p\)：策略日收益率标准差
- \(\sqrt{252}\)：年化因子（252个交易日）

**评判标准**：
- < 0：策略亏损
- 0~1：可接受
- 1~2：良好
- > 2：优秀

> **数值示例**：策略日均收益 0.05%，日波动率 0.8%，无风险利率 3%
> - 超额日收益 = 0.05% - 3%/252 = 0.05% - 0.012% = 0.038%
> - Sharpe = 0.038% / 0.8% × √252 = 0.0475 × 15.87 = **0.75**（可接受）

### 最大回撤（Max Drawdown）

**定义**：从净值最高点到最低点的最大跌幅。

$$MDD = \frac{Peak - Trough}{Peak}$$

**评判标准**：
- < 10%：保守型策略
- 10%-20%：中等风险
- 20%-30%：较高风险
- > 30%：高风险

> **数值示例**：策略净值序列为 100万→108万→105万→112万→98万→115万
> - 最高点 = 115万，但从112万回撤到98万时回撤最大
> - MDD = (112 - 98) / 112 = **12.5%**

### 胜率（Win Rate）

$$胜率 = \frac{盈利交易次数}{总交易次数}$$

> **示例**：20笔交易中12笔盈利、8笔亏损，胜率 = 12/20 = **60%**

### 盈亏比（Profit Factor）

$$盈亏比 = \frac{平均盈利金额}{平均亏损金额}$$

> **示例**：盈利交易平均每笔赚 3000元，亏损交易平均每笔亏 1200元
> 盈亏比 = 3000 / 1200 = **2.5**（每亏1元，能赚回2.5元）

### 策略健康度标准

| 指标 | 达标线 | 含义 |
|------|--------|------|
| 年化收益率 | ≥ 20% | 基本收益要求 |
| 最大回撤 | ≤ 20% | 可承受的风险 |
| 盈亏比 | ≥ 2.0 | 赚的比亏的多 |
| 胜率 | ≥ 35% | 趋势策略胜率可以偏低 |

> **本系统应用**
>
> `metrics.py` 提供了完整的绩效指标计算：
> - `calc_sharpe_ratio()`：夏普比率（年化，无风险利率默认3%）
> - `calc_max_drawdown()`：最大回撤（含回撤起止日期）
> - `calc_sortino_ratio()`：Sortino比率（只考虑下行波动）
> - `calc_calmar_ratio()`：Calmar比率 = 年化收益 / 最大回撤
> - `calc_win_rate()`：胜率
> - `calc_profit_factor()`：盈亏比
> - `calc_expectancy()`：每笔期望收益 = 胜率 × 平均盈利 - 败率 × 平均亏损
> - `calc_cvar()`：CVaR（95%置信度下的平均损失）
> - `calc_alpha_beta()`：CAPM回归（Alpha、Beta、R²、信息比率）

## 4.4 Kelly公式（仓位管理）

### 什么是Kelly公式

> **打个比方**：Kelly公式回答的是一个关键问题："每次应该下多大的注？"
> 假设你玩一个抛硬币游戏：正面赢2元，反面亏1元（盈亏比2:1），正面概率60%。
> Kelly公式告诉你：每次拿出总资金的40%来下注，长期下来资金增长最快。
> 但实际炒股中，我们只用一半（半Kelly=20%），因为股市比抛硬币不确定得多。

Kelly公式计算的是在给定胜率和盈亏比下，使资金长期增长率最大化的最优仓位比例。

### 计算公式

$$f^* = \frac{p \times b - q}{b}$$

- \(f^*\)：最优仓位比例
- \(p\)：胜率
- \(q\)：败率 = 1 - p
- \(b\)：盈亏比（平均盈利/平均亏损）

**计算示例**：胜率 60%，盈亏比 2.0
- f* = (0.60 × 2.0 - 0.40) / 2.0 = (1.20 - 0.40) / 2.0 = 0.80 / 2.0 = **40%**
- 理论最优仓位为40%

### 半Kelly（Half Kelly）

实际交易中，全Kelly仓位波动太大，一次连续亏损可能回撤很深。因此实务中普遍使用**半Kelly**：

$$半Kelly = f^* \times 0.5$$

> **示例**：全Kelly = 40%，半Kelly = **20%**
> 牺牲约25%的期望收益，但回撤降低约50%，风险收益比更优。

> **本系统应用**
>
> `kelly.py` 实现了完整的Kelly仓位管理：
> - `kelly_position()`：全Kelly计算，限制单只最大仓位 **15%**
> - `half_kelly_position()`：半Kelly（推荐），降低波动
> - `kelly_from_trades()`：从交易记录自动计算胜率和盈亏比，输出半Kelly仓位
> - `portfolio_kelly()`：组合Kelly分配，总仓位超过 **90%** 时等比缩放
>
> **实际示例**：假设某策略历史胜率为55%，盈亏比为2.2
> - 全Kelly = (0.55 × 2.2 - 0.45) / 2.2 = (1.21 - 0.45) / 2.2 = **34.5%**
> - 半Kelly = 34.5% × 0.5 = **17.3%**
> - 受限于单只最大15% → 实际仓位 = **15%**

## 4.5 风险平价（Risk Parity）

### 什么是风险平价

> **打个比方**：假设你和3个朋友合伙开船，其中一人体重200斤（高波动股票），三人各100斤。
> 如果四人平均坐（等权配置），船会严重向200斤那边倾斜。
> 风险平价的做法是：让200斤的人坐中间，100斤的人坐两边——让每个人对船的"倾斜贡献"相等。
> 通俗来说：**波动大的股票少买点，波动小的股票多买点，让每只股对总风险的贡献一样大**。

风险平价的核心思想是：**让每只股票对组合总风险的贡献相等**。

传统等权配置（每只股票配25%）的问题：高波动股票的风险贡献远大于低波动股票。

> **示例**：4只股票等权各25%，波动率分别为 20%、25%、35%、50%。
> 第4只股票（50%波动率）的风险贡献是第1只（20%波动率）的2.5倍。
> 组合实际被第4只股票主导。

### 计算公式

$$w_i = \frac{1/\sigma_i}{\sum_{j=1}^{n}(1/\sigma_j)}$$

- \(w_i\)：第 i 只股票的权重
- \(\sigma_i\)：第 i 只股票的年化波动率

**计算示例**：3只股票波动率分别为 20%、30%、40%
- 1/σ 分别为：5.0、3.33、2.5
- 总和 = 5.0 + 3.33 + 2.5 = 10.83
- 权重：5.0/10.83 = **46.2%**、3.33/10.83 = **30.7%**、2.5/10.83 = **23.1%**

结果：低波动股票获得更高权重，高波动股票权重被压低，风险贡献趋于均衡。

### 最大权重限制

为避免单一股票权重过高，系统设置了自适应上限：

$$max\_weight = \max(0.15, \frac{0.9}{n})$$

其中 n 为股票数量。当某只股票权重超过上限时，截断并重新归一化。

> **本系统应用**
>
> `risk_parity.py` 提供了三种风险平价方法：
> 1. `risk_parity_weights()`：基础版，输入各股票年化波动率，输出权重（含自适应max_weight限制）
> 2. `risk_parity_from_returns()`：从日收益率数据自动计算波动率，回看窗口默认60天
> 3. `equal_risk_contribution()`：等风险贡献（ERC），基于年化协方差矩阵的版本
>
> **实际示例**：假设持仓5只股票，波动率分别为 25%、30%、35%、40%、50%
> - 风险平价权重：0.244、0.203、0.174、0.153、0.150
> - max_weight = max(0.15, 0.9/5) = 0.18
> - 截断后：0.18、0.18、0.174、0.153、0.150，归一化后总和=1

## 4.6 信号衰减与共识评分

### 信号衰减

> **打个比方**：信号衰减就像"新闻的时效性"。今天的头条新闻明天就没人看了，
> 股市信号也一样：今天出现的买入信号，拖到3天后才执行，效果已经大打折扣。
> 这就是为什么本系统的买入条件单只有3天有效期——过期自动作废。
> 但止损信号永远有效——就像"火灾警报"不管什么时候响都必须立即跑。

量化信号不是永久有效的，随着时间推移其有效性会逐渐降低。

**衰减曲线**（基于历史回测统计）：

| 信号类型 | T+1 | T+2 | T+3 | T+5 |
|---------|-----|-----|-----|-----|
| 缩量回踩买入 | 100% | 82% | 61% | 35% |
| 放量突破买入 | 100% | 75% | 50% | 20% |
| 双买点共振 | 100% | 88% | 72% | 50% |
| 止损 | 100% | 100% | 100% | 100% |
| 止盈 | 100% | 95% | 90% | 80% |
| 加仓 | 100% | 85% | 65% | 40% |

**关键发现**：
- **买入信号衰减最快**：T+3后有效性降到50%以下，5天后基本失效
- **止损信号无衰减**：保护性信号，永久有效
- **双买点共振衰减最慢**：共振信号更可靠，T+5仍有50%有效性

> **条件单有效期管理**：
> - 买入条件单：3个交易日后自动过期
> - 止损条件单：永久有效
> - 止盈条件单：每周根据最新价格更新

> **本系统应用**
>
> `signal_decay.py` 的 `SignalDecayManager` 管理信号生命周期：
> - `evaluate_freshness()`：根据信号产生日期计算当前有效性
> - `apply_validity()`：为条件单设置过期时间
> - 过期信号自动标记为撤销

### 共识评分

共识机制解决的核心问题是：当多个分析模块给出矛盾结论时，如何做出最终判断？

**权重分配**：

| 模块 | 权重 | 数据来源 |
|------|------|---------|
| 趋势策略信号 | 35% | DK信号强度和方向 |
| 趋势预测评分 | 30% | 综合预测分数 |
| 量价健康度 | 20% | 量价配合分析 |
| 资金流维度 | 15% | 资金流综合评分 |

**共识输出**：

| 方向 | 分数范围 | 含义 |
|------|---------|------|
| 看多 | +50 ~ +100 | 多个模块一致看好 |
| 中性 | -20 ~ +20 | 方向不明确 |
| 看空 | -100 ~ -50 | 多个模块一致看空 |
| 分歧 | 分数在中间但模块间矛盾大 | 需要人工判断 |

> **示例**：某股票趋势策略给出+25（看多），趋势预测+18（看多），量价+12（看多），资金流-5（中性偏空）。
> 共识分 = 25 + 18 + 12 + (-5) = **+50**（看多，置信度较高）。

> **本系统应用**
>
> `consensus.py` 的 `compute_consensus()` 函数整合四个维度的判断：
> - 检测模块间矛盾（如技术看多但资金看空）
> - 输出统一方向 + 置信度 + 矛盾原因说明
> - 生成结构化操作建议（持有/减仓/清仓/加仓/观望）

| 概念 | 一句话解释 | 本系统对应 |

| 多因子模型 | 多维度综合评分选股 | `multi_factor.py`（四维30/30/20/20） |
| 回测 | 用历史数据验证策略 | `caopan_signal.py → backtest()` |
| 前视偏差 | 误用未来数据 | 回测只使用历史已公开数据 |
| 过拟合 | 参数过度适应历史 | 样本内外验证 + 参数鲁棒性检验 |
| 夏普比率 | 风险调整后的收益 | `metrics.py → calc_sharpe_ratio()` |
| 最大回撤 | 最大亏损幅度 | `metrics.py → calc_max_drawdown()` |
| Kelly公式 | 最优仓位计算 | `kelly.py`（半Kelly + 15%上限） |
| 风险平价 | 等风险贡献配置 | `risk_parity.py`（波动率倒数加权） |
| 信号衰减 | 信号随时间失效 | `signal_decay.py`（T+3后衰减>50%） |
| 共识评分 | 多模块统一判断 | `consensus.py`（35/30/20/15权重） |

## 本节小结

| 核心要点 | 一句话总结 |
|---------|------------|
| 多因子模型 | 像高考总分制，多维度打分选股，本系统用四维(30/30/20/20)评0-100分 |
| 回测 | 用历史数据"模拟考试"，但要防止过拟合（背答案） |
| 夏普比率 | 性价比指标，>1良好，>2优秀 |
| 最大回撤 | 最惨时亏多少，本系统要求≤20% |
| Kelly公式 | 计算"每次下多大注"，本系统用半Kelly+15%上限 |
| 风险平价 | 波动大的少买、波动小的多买，均衡风险贡献 |
| 信号衰减 | 买入信号3天后失效，止损信号永久有效 |
| 共识评分 | 多模块"投票"决定最终方向，避免单一指标误判 |

**新手记住三条就够用**：
1. 不追过期信号——买入信号超过3天就不追了
2. 不押全部身家——单只股票最多买总资金的15%
3. 看综合分不看单一指标——多个维度都说好才是真的好

## 常见疑问FAQ

**Q1：回测胜率61.8%意味着什么？会不会太低了？**

A：61.8%胜率在量化策略中已经很不错了。关键是盈亏比：
- 本系统盈亏比约2.5:1（平均赚的钱是亏的2.5倍）
- 算笔账：10次交易，6次赚×2500元=15000，4次亏×1000元=4000，净赚11000元
- 即使胜率只有50%，只要盈亏比>2，长期仍然赚钱
- 真正危险的是"胜率90%但盈亏比0.5"——赢9次小钱，亏1次大钱就全吐回去

**Q2：为什么用半Kelly而不是全Kelly？**

A：打个比方，全Kelly就像"每次把40%身家押上"，连续亏3次就只剩21.6%了（0.6³=0.216）。
半Kelly每次只押20%，连续亏3次还剩51.2%（0.8³=0.512），心理压力小得多。
牺牲约25%的期望收益，换来约50%的回撤降低——非常划算的"保险费"。

**Q3：多因子评分70分以上就一定能赚钱吗？**

A：不一定。70分只是"概率上更可能涨"，不是保证。本系统的逻辑是：
- 70分以上 → 允许建仓（但还要过风控17道关卡）
- 建仓后 → 严格止损（单笔最大亏损≤总资金2%）
- 即使判断错了，亏损也被控制在可接受范围内
- 量化交易的核心不是"每次都对"，而是"对的时候多赚，错的时候少亏"

**Q4：信号衰减表怎么看？举个实际例子？**

A：假设周一系统发出"缩量回踩买入"信号：
- 周二执行（T+1）：有效性100%，最佳买点
- 周三执行（T+2）：有效性82%，还可以
- 周四执行（T+3）：有效性61%，勉强可做
- 下周一（T+5）：有效性35%，**不建议再追**
- 所以本系统规定买入条件单3天后自动过期

**Q5：本系统的CANSLIM选股和多因子模型是什么关系？**

A：它们是两套并行的评分体系，服务不同场景：
- **CANSLIM**（`stock_screener.py`）：用于每日选股，五因子各20分满分100分，侧重"趋势启动+量价突破"
- **多因子**（`multi_factor.py`）：用于持仓诊断，四维(30/30/20/20)满分100分，侧重"综合健康度"
- 两者互补：CANSLIM决定"买什么"，多因子决定"持有的股票状态如何"
