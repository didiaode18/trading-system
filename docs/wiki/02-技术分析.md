# 第2篇：技术指标详解

> 技术指标是通过数学公式对股价历史数据进行加工，生成辅助买卖决策的数值信号。
> 本篇详解7个核心技术指标，每个指标包含：计算公式、参数含义、买卖信号、本系统应用。

---

## 2.1 MA / EMA：移动平均线

### MA（简单移动平均线）

**计算公式**：

$$MA_N = \frac{C_1 + C_2 + \cdots + C_N}{N}$$

其中 \(C_i\) 为第 i 天的收盘价，N 为周期天数。

**参数含义**：
- MA5（5日线）：一周趋势，短线交易者常用
- MA10（10日线）：两周趋势，中短线分界
- MA20（20日线）：月线趋势，中线参考
- MA60（60日线）：季线趋势，长线牛熊分界

**计算示例**（MA5）：最近5天收盘价为 20.1、20.5、19.8、20.3、20.8
$$MA5 = \frac{20.1 + 20.5 + 19.8 + 20.3 + 20.8}{5} = 20.30$$

### EMA（指数移动平均线）

**计算公式**：

$$EMA_{today} = \alpha \times C_{today} + (1-\alpha) \times EMA_{yesterday}$$

其中 \(\alpha = \frac{2}{N+1}\) 为平滑系数。

**参数含义**：α 越大，对最新价格越敏感。EMA13 的 α = 2/14 ≈ 0.143，EMA34 的 α = 2/35 ≈ 0.057。

### 买卖信号

| 信号类型 | 条件 | 含义 |
|---------|------|------|
| 金叉 | 短期均线上穿长期均线 | 买入信号 |
| 死叉 | 短期均线下穿长期均线 | 卖出信号 |
| 多头排列 | MA5 > MA10 > MA20 > MA60 | 强势上涨趋势 |
| 空头排列 | MA5 < MA10 < MA20 < MA60 | 下跌趋势 |

> **本系统应用**
>
> 操盘密码使用 EMA13（`ll_fast`）和 EMA34（`ll_slow`）作为控盘生命线。
> - D点（买点）= EMA13 上穿 EMA34（金叉）
> - K点（卖点）= EMA13 下穿 EMA34（死叉）
> - 5级趋势分级：根据双线的斜率方向和开口大小，分为强上升/弱上升/震荡/弱下跌/强下跌
>
> 系统还引入了 ATR 自适应机制：当 ATR 处于高分位（>80%）时，EMA周期自动拉长20%以降低噪音；
> 当 ATR 处于低分位（<20%）时，周期缩短20%以提升灵敏度。参见 `caopan_signal.py → compute_adaptive_life_lines()`。

## 2.2 MACD：异同移动平均线

### 计算公式

MACD 由三个数值组成：

$$DIF = EMA_{12} - EMA_{26}$$
$$DEA = EMA_9(DIF)$$
$$MACD柱 = 2 \times (DIF - DEA)$$

**参数含义**：
- **DIF（快线）**：12日EMA与26日EMA的差值，反映短期与中期趋势的偏离程度
- **DEA（慢线/信号线）**：DIF的9日EMA，是DIF的平滑线
- **MACD柱**：DIF与DEA的差值放大2倍，红柱=多头，绿柱=空头

### 计算示例

假设当前：EMA12 = 25.30，EMA26 = 24.50
- DIF = 25.30 - 24.50 = **0.80**（快线在零轴上方，短期趋势强于中期）
- 若昨日 DEA = 0.65，今日 DEA = 0.65 × (8/10) + 0.80 × (2/10) = **0.68**
- MACD柱 = 2 × (0.80 - 0.68) = **0.24**（红柱，多头力量增强）

### 买卖信号

| 信号 | 条件 | 操作 |
|------|------|------|
| 金叉（零轴上） | DIF 上穿 DEA，且都在零轴上方 | 强势买入（趋势延续） |
| 金叉（零轴下） | DIF 上穿 DEA，且都在零轴下方 | 弱势反弹（谨慎买入） |
| 死叉（零轴上） | DIF 下穿 DEA，且都在零轴上方 | 回调信号（减仓） |
| 死叉（零轴下） | DIF 下穿 DEA，且都在零轴下方 | 强势卖出（趋势延续） |
| 顶背离 | 价格创新高，DIF 未创新高 | 顶部信号，准备卖出 |
| 底背离 | 价格创新低，DIF 未创新低 | 底部信号，准备买入 |

> **本系统应用**
>
> 本系统不直接使用经典MACD，而是将 EMA13/EMA34 交叉升级为「三重共振DK信号」：
> 1. 均线交叉（基础信号）
> 2. 量能验证（D点需放量 ≥ 20日均量×1.2）
> 3. 趋势匹配（上升趋势只保留D点，下跌只保留K点）
>
> 这种设计在保留MACD金叉/死叉核心思想的同时，大幅减少了假信号。

## 2.3 RSI：相对强弱指标

### 计算公式

$$RSI_N = \frac{\text{平均上涨幅度}}{\text{平均上涨幅度} + \text{平均下跌幅度}} \times 100$$

其中"平均上涨/下跌幅度"为 N 天内的指数移动平均。

**参数含义**：
- RSI 取值 0~100
- RSI > 70：超买区（多头过热，可能回调）
- RSI < 30：超卖区（空头过度，可能反弹）
- RSI = 50：多空平衡线

### 计算示例（RSI6）

最近6天涨跌幅分别为：+2%、-1%、+3%、+1%、-0.5%、+2.5%
- 上涨天数：4天，涨幅合计 8.5%，平均上涨 = 8.5%/4 = 2.125%
- 下跌天数：2天，跌幅合计 1.5%，平均下跌 = 1.5%/2 = 0.75%
- RSI = 2.125 / (2.125 + 0.75) × 100 = **73.9**（进入超买区）

### 买卖信号

| 信号 | 条件 | 操作 |
|------|------|------|
| 超买卖出 | RSI > 80 | 减仓或观望 |
| 超卖买入 | RSI < 20 | 关注抄底机会 |
| 背离 | 价格新高但RSI未新高 | 顶部信号 |

> **本系统应用**
>
> 系统在 RSI > 80 时降低信号权重。具体地，在乖离率4档指引中：
> - 偏离 > 超买阈值（默认约10%）→ "超买减仓1/2"
> - 偏离 > 偏高阈值 → "偏高减仓1/3"
> - 偏离在正常区间 → "正常持有"
> - 偏离 < 超卖阈值 → "超卖观察"
>
> 参见 `caopan_signal.py → _deviation_guidance()`。

## 2.4 KDJ：随机指标

### 计算公式

$$RSV = \frac{C - L_N}{H_N - L_N} \times 100$$
$$K = \frac{2}{3} \times K_{yesterday} + \frac{1}{3} \times RSV$$
$$D = \frac{2}{3} \times D_{yesterday} + \frac{1}{3} \times K$$
$$J = 3K - 2D$$

**参数含义**：
- **RSV（未成熟随机值）**：当前价格在 N 天价格区间中的位置（0-100）
- **K线**：RSV 的平滑值，反映趋势方向
- **D线**：K线的平滑值，反映趋势确认
- **J线**：K与D的偏离程度，最灵敏（可超出0-100范围）

### 计算示例（N=9）

最近9天最高价 = 22.00，最低价 = 18.00，今日收盘 = 21.00
- RSV = (21.00 - 18.00) / (22.00 - 18.00) × 100 = **75**
- 假设昨日 K = 65，D = 60
- 今日 K = 2/3 × 65 + 1/3 × 75 = **68.3**
- 今日 D = 2/3 × 60 + 1/3 × 68.3 = **62.8**
- 今日 J = 3 × 68.3 - 2 × 62.8 = **79.3**

### 买卖信号

| 信号 | 条件 | 操作 |
|------|------|------|
| 金叉买入 | K 上穿 D（且在20以下更有效） | 买入 |
| 死叉卖出 | K 下穿 D（且在80以上更有效） | 卖出 |
| J值超买 | J > 100 | 超买，准备减仓 |
| J值超卖 | J < 0 | 超卖，关注买入 |

## 2.5 BOLL：布林带

### 计算公式

$$中轨 = MA_{20}$$
$$上轨 = MA_{20} + 2 \times \sigma_{20}$$
$$下轨 = MA_{20} - 2 \times \sigma_{20}$$

其中 \(\sigma_{20}\) 为20日收盘价的标准差。

**参数含义**：
- 中轨：20日均线，趋势基准线
- 上轨：中轨 + 2倍标准差，压力位
- 下轨：中轨 - 2倍标准差，支撑位
- 带宽 = (上轨 - 下轨) / 中轨，衡量波动率

### 计算示例

20日均价 = 25.00，20日标准差 = 1.20
- 上轨 = 25.00 + 2 × 1.20 = **27.40**
- 下轨 = 25.00 - 2 × 1.20 = **22.60**
- 带宽 = (27.40 - 22.60) / 25.00 = **19.2%**

### 买卖信号

| 信号 | 条件 | 操作 |
|------|------|------|
| 突破上轨 | 收盘 > 上轨 | 强势突破，可能继续上涨或回归中轨 |
| 跌破下轨 | 收盘 < 下轨 | 弱势破位，可能继续下跌或回归中轨 |
| 缩口 | 带宽收窄到极致 | 即将变盘，关注突破方向 |
| 开口 | 带宽快速扩大 | 趋势加速（沿突破方向） |

> **本系统应用**
>
> 本系统的ATR自适应趋势通道与布林带思路类似：用ATR（平均真实波幅）构建动态支撑/压力区间。
> 系统计算均线开口率 `ll_spread = (ll_fast - ll_slow) / ll_slow`，
> 开口放大+趋势同向 = 强信号，开口收窄 = 趋势可能反转。

## 2.6 ATR：平均真实波幅

### 计算公式

首先计算真实波幅（TR）：

$$TR = \max(High - Low,\ |High - Close_{prev}|,\ |Low - Close_{prev}|)$$

然后：

$$ATR_N = \frac{TR_1 + TR_2 + \cdots + TR_N}{N}$$

**参数含义**：
- TR 取三者最大值，确保捕捉到跳空缺口
- ATR 衡量的是"每日平均波动多少元"，不判断方向，只衡量波动幅度
- 常用参数：ATR14（14日）、ATR20（20日）

### 计算示例

今日：最高 21.50，最低 20.30，昨收 21.00
- TR1 = 21.50 - 20.30 = 1.20
- TR2 = |21.50 - 21.00| = 0.50
- TR3 = |20.30 - 21.00| = 0.70
- TR = max(1.20, 0.50, 0.70) = **1.20**
- 若14日TR平均值为 0.95，则 ATR14 = **0.95**（日均波动约0.95元）

### 买卖信号

ATR 不直接产生买卖信号，但广泛用于：

1. **止损设定**：止损位 = 入场价 - N × ATR（N通常取1.5~3）
2. **仓位管理**：波动大的股票（ATR高）配置更少仓位
3. **过滤假突破**：突破幅度 < 1倍ATR，视为噪音

> **本系统应用**
>
> ATR 在本系统中承担多重角色：
> 1. **自适应EMA周期**：ATR分位数决定EMA是否拉长/缩短（`compute_adaptive_life_lines`）
> 2. **止损计算**：止损位 = max(LL2下方2%, 入场价 - 2倍ATR)，防止止损太远
> 3. **目标位计算**：目标位 = 入场价 + ATR × 3.5（第二目标位）
> 4. **假信号回检窗口**：高波动（ATR/price > 3%）→ 回检5天，低波动（< 1.5%）→ 回检3天
>
> 参见 `caopan_signal.py → calc_risk_reward()` 和 `_detect_false_signals()`。

## 2.7 CCI：顺势指标

### 计算公式

$$CCI = \frac{TP - MA_{TP}}{0.015 \times MD}$$

其中：
- TP（典型价格）= (High + Low + Close) / 3
- MA_TP = TP 的 N 日移动平均
- MD = TP 与 MA_TP 的 N 日平均绝对偏差

**参数含义**：
- CCI 衡量股价偏离统计平均值的程度
- CCI > +100：超买区，股价处于强势
- CCI < -100：超卖区，股价处于弱势
- CCI 在 ±100 之间：震荡区

### 计算示例

假设14日TP均值 = 20.50，今日 TP = 22.00，平均偏差 = 0.80
- CCI = (22.00 - 20.50) / (0.015 × 0.80) = 1.50 / 0.012 = **125**
- CCI > 100，进入超买区域

### 买卖信号

| 信号 | 条件 | 操作 |
|------|------|------|
| 突破+100 | CCI 从下方突破 +100 | 强势信号，可跟进买入 |
| 跌破-100 | CCI 从上方跌破 -100 | 弱势信号，考虑卖出 |
| 回归零轴 | CCI 从极值回归零轴 | 趋势可能反转 |

## 2.8 技术指标综合速查表

| 指标 | 类型 | 最佳场景 | 主要局限 |
|------|------|---------|----------|
| MA/EMA | 趋势跟踪 | 单边趋势行情 | 震荡市产生大量假信号 |
| MACD | 趋势+动量 | 判断趋势方向和强度 | 滞后性较强 |
| RSI | 超买超卖 | 震荡市的高抛低吸 | 趋势市中长期钝化 |
| KDJ | 超买超卖 | 短线买卖点捕捉 | 灵敏度过高，假信号多 |
| BOLL | 波动率通道 | 判断突破和回归 | 缩口后方向不确定 |
| ATR | 波动率 | 止损/仓位管理 | 不判断方向 |
| CCI | 顺势指标 | 识别趋势启动 | 信号频率较低 |
