### 模块间依赖关系

```
config.py ←── 所有模块（全局配置中心）
     │
     ├── data/ ←── strategy/ ←── risk/ ←── output/
     │                  │             │
     │                  └── position/ ←┘
     │
     ├── backtest/ ←── scheduler.py
     ├── ml/       ←── scheduler.py
     └── factors/  ←── scheduler.py
```

> **本系统应用**：`config.py` 作为全局配置中心，被几乎所有模块导入。资金参数（`TOTAL_CAPITAL`）、邮箱配置、股票池（`STOCK_POOL`）、风控参数（`RISK_UNIFIED_CONFIG`）等均在此处集中管理，修改参数只需编辑此文件。

## 二、数据流图

### 2.1 盘后分析完整链路

```
数据获取                    分析计算                    信号生成
┌──────────┐            ┌──────────┐            ┌──────────┐
│baostock  │──日线K线──→│趋势策略   │──买卖信号──→│风控引擎   │
│akshare   │──实时行情──→│DK信号    │──DK评分───→│14道关卡   │
│东方财富   │──资金流向──→│资金分析   │──资金评分──→│仓位校验   │
└──────────┘            │筹码分布   │──控盘度───→│盈亏比检查  │
                        │板块轮动   │──板块动量──→└─────┬────┘
                        │多因子选股 │──综合评分──→      │
                        └──────────┘                   │
                                                       │
                        ┌──────────┐            ┌──────▼───┐
                        │邮件发送   │←──HTML报告──│输出层     │
                        │条件单生成 │←──操作计划──│仓位计划   │
                        │盘中预警   │←──预警信号──│止损/止盈  │
                        └──────────┘            └──────────┘
```

### 2.2 单只股票的分析流程

```
1. data_loader.get_stock_data()     → 获取60-300日K线
2. trend_strategy.compute_indicators() → 计算MA/MACD/RSI/ATR/布林带
3. caopan_signal.CaopanEngine.analyze() → 控盘生命线 + DK信号 + 资金监控
4. chip_distribution.ChipAnalyzer.analyze() → 筹码分布 + 获利盘 + 控盘度
5. anti_manipulation.AntiManipulationAnalyzer.analyze() → 洗盘/出货识别
6. consensus.compute_consensus() → 四维度多空共识评分
7. risk_control.UnifiedRiskEngine.check() → 风控关卡链校验
8. position.calc_first_batch() → Kelly+ATR仓位计算
```

## 三、调度时序图

系统采用 **"4+1"报告体系**（4份定时报告 + 盘中预警）：

### 3.1 交易日时间线

```
08:30 ──── 盘前作战计划（scheduler.run_forecast_morning）
  │         内容: 大盘展望 + 持仓操作清单 + 关键价位 + 仓位建议
  │         邮件: [盘前作战计划] 日期 | N项操作
  │
09:25 ──── 竞价后选股（scheduler.run_morning_screener）
  │         内容: 全赛道选股扫描 + CANSLIM评分
  │         邮件: [选股推荐] N只入选
  │
09:30 ──── 盘中监控启动（后台线程）
  │         IntradayMonitor 每30秒轮询持仓实时行情
  │         触发条件: 急跌>3% / 大盘急跌>1.5% / 振幅>8%
  │         联动: 触发时设置 risk_state.intraday_risk_flags
  │
10:00 ──── 禁止新开仓时段开始
  │
13:30 ──── 禁止新开计划外标的
  │
14:30 ──── 禁止新开仓时段开始
  │
15:01 ──── 盘中监控停止
  │
15:30 ──── 盘后综合日报（scheduler.run_daily_task）
  │         内容: 数据更新 → 信号扫描 → 九大模块分析 → 综合日报
  │         附加: ML预测 + IC因子监控 + 预测验证回填
  │         邮件: [盘后综合日报] 日期 | 买N/卖N | 风险N分
  │
19:00 ──── 条件单提醒（scheduler.run_morning_reminder）
  │         内容: 持仓止损/止盈条件单 + 买入推荐条件单 + 新闻风险扫描
  │         邮件: [条件单] 东方财富智能条件单 - 日期
  │
```

### 3.2 周末时间线

```
周六 10:00 ── 周度回顾（scheduler.run_weekly_portfolio）
  │            内容: 本周绩效 + 归因分析 + 压力测试 + 下周建议
  │            邮件: [周度回顾] 日期 | 周收益+x.x%
  │
周六 11:00 ── ML模型训练（scheduler._run_weekly_ml_training）
  │            内容: 全市场XGBoost模型训练 + 交叉验证
  │
周日 10:00 ── 股票池更新提醒
  │
每月1日 09:00 ── Walk-Forward验证（scheduler._run_monthly_walk_forward）
                 内容: 60天训练/20天验证滚动窗口，检测过拟合
```

### 3.3 盘中预警联动

```
IntradayMonitor(09:30-15:00)
  │
  ├── 检测到急跌>3% ──→ 设置 systemic_risk 标记
  │                       └── 风控引擎: 总仓位上限强制降至30%
  │
  ├── 检测到盘中暂停信号 ──→ 设置 intraday_pause 标记
  │                          └── 风控引擎: 拒绝所有新买入
  │
  └── 15:30 ──→ 自动过期清除所有盘中风险标记
```

## 四、外部数据源

| 数据源 | 用途 | Python库 | 特点 |
|--------|------|----------|------|
| baostock | 主数据源：历史日线K线 | `baostock>=0.8.8` | 免费，前复权，稳定 |
| akshare | 备用数据源+板块数据 | `akshare>=1.10.0` | 东方财富接口，板块资金流 |
| 东方财富 | 实时行情+条件单格式 | 内置HTTP请求 | 条件单直接对接券商APP |

### 数据获取流程

```python
# data/data_loader.py 中的优先级逻辑:
1. 优先从本地SQLite缓存(stock_db.db)读取
2. 缓存不足时从baostock拉取增量数据
3. baostock失败时回退到akshare
4. 所有数据统一为 pandas DataFrame 格式
```

> **本系统应用**：`data/data_loader.py` 维护一个本地SQLite数据库（`data/stock_db.db`），避免重复拉取历史数据。每日盘后15:30的 `run_daily_task()` 会调用 `skip_update=False` 触发增量更新。

## 五、文件依赖关系

### 5.1 核心配置文件

`config.py` 是整个系统的配置中心，包含：

| 配置段 | 内容 | 示例 |
|--------|------|------|
| 资金配置 | 总资金、可用现金、现金保留比例 | `TOTAL_CAPITAL = 714_324.76` |
| 股票池 | 核心操作池 + 全赛道候选池 | `STOCK_POOL` + `SECTOR_CANDIDATES` |
| 趋势参数 | 均线周期、RSI、MACD、布林带 | `MA_SHORT = 20` |
| 止损参数 | 初始止损、移动止损档位、时间止损 | `INITIAL_STOP_LOSS_PCT = 0.10` |
| 风控参数 | 统一风控配置（14道关卡） | `RISK_UNIFIED_CONFIG` |
| 邮件配置 | SMTP服务器、发件人、授权码 | `EMAIL_SMTP_HOST = "smtp.qq.com"` |
| 操盘密码 | DK信号、生命线、资金监控参数 | `CAOPAN_CONFIG` |
| 纪律配置 | 交易硬约束（基于真实委托验证） | `DISCIPLINE_CONFIG` |

### 5.2 关键数据文件

| 文件 | 位置 | 用途 |
|------|------|------|
| `holdings.json` | 项目根目录 | 当前持仓数据（手动维护） |
| `stock_db.db` | `data/` | 历史K线本地缓存 |
| `trade_journal.db` | `data/` | 交易日志（自动记录） |
| `risk_state.json` | `output/` | 风控状态持久化 |
| `vol_scale_state.json` | `data/` | 波动率缩放状态 |
| `capital_flow_cache.json` | `data/` | 资金流缓存 |

## 六、三大入口程序

| 入口 | 命令 | 实际调用 |
|------|------|----------|
| `run.py` | `python run.py report/orders/auto` | 统一CLI，转发到各子脚本 |
| `scheduler.py` | `python scheduler.py` | 常驻调度器，按时间表自动执行 |
| `auto_scheduler.py` | `python auto_scheduler.py` | 轻量守护进程，盘后+盘中两阶段 |

### run.py 命令映射

```
python run.py report   → generate_holdings_report.py  （盘后综合分析）
python run.py orders   → daily_orders.py               （条件单生成）
python run.py screen   → main.py                       （全赛道选股扫描）
python run.py caopan   → caopan_runner.py              （操盘密码分析）
python run.py auto     → auto_scheduler.py             （全自动调度）
python run.py backtest → backtest_real.py              （策略回测）
python run.py status   → 内置                           （系统状态检查）
```
