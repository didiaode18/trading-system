## 一、环境配置

### 1.1 安装 Python

系统要求 Python 3.10+，推荐使用 [Python 官网](https://www.python.org/downloads/) 的 Windows 安装包。

安装时勾选 **"Add Python to PATH"**。

### 1.2 安装依赖

打开 PowerShell，进入项目根目录：

```powershell
cd d:\workspace\trading-system
pip install -r requirements.txt
```

核心依赖清单：

| 库名 | 版本要求 | 用途 |
|------|----------|------|
| baostock | ≥0.8.8 | 主数据源（免费A股日线） |
| akshare | ≥1.10.0 | 备用数据源（东方财富） |
| pandas | ≥1.5.0 | 数据处理 |
| numpy | ≥1.21.0 | 数值计算 |
| openpyxl | ≥3.0.0 | 生成条件单Excel |
| schedule | ≥1.2.0 | 定时调度 |
| scipy | — | 统计分析 |

### 1.3 邮箱配置

系统通过 QQ 邮箱 SMTP 发送报告邮件。

**步骤：**

1. 登录 QQ 邮箱 → 设置 → 账户 → POP3/SMTP 服务 → 开启
2. 生成授权码（一串16位字符）
3. 设置环境变量（推荐，不硬编码在代码中）：

```powershell
# PowerShell 临时设置
$env:EMAIL_AUTH_CODE = "你的授权码"

# 或永久设置：系统属性 → 环境变量 → 新增 EMAIL_AUTH_CODE
```

4. 编辑 `trading_system/config.py`，确认以下配置：

```python
EMAIL_SMTP_HOST = "smtp.qq.com"
EMAIL_SMTP_PORT = 465
EMAIL_SENDER = "你的QQ邮箱@qq.com"
EMAIL_AUTH_CODE = os.environ.get("EMAIL_AUTH_CODE", "")
EMAIL_RECEIVER = "收件邮箱@qq.com"
```

> **提示**：授权码不是QQ密码，需要在QQ邮箱网页端的"设置→账户"中单独生成。

### 1.4 验证环境

```powershell
python run.py status
```

正常输出应显示：
```
[依赖检查]
  ✅ baostock
  ✅ akshare
  ✅ pandas
  ✅ numpy
  ✅ scipy
[配置文件]
  ✅ config.py
  ✅ holdings.json (N只持仓)
[邮件配置]
  ✅ 邮件模块可用
```

## 二、持仓配置

### 2.1 holdings.json 格式

持仓数据存储在项目根目录的 `holdings.json` 文件中，JSON 格式：

```json
{
  "002409": {
    "name": "雅克科技",
    "shares": 200,
    "buy_price": 151.348,
    "current_price": 155.900,
    "stop_loss": 140.00,
    "highest": 160.00,
    "buy_date": "2025-04-10",
    "reason": "半导体材料龙头趋势买入"
  }
}
```

### 2.2 字段说明

| 字段 | 类型 | 含义 | 示例 |
|------|------|------|------|
| 键名 | string | 股票代码（6位） | `"002409"` |
| `name` | string | 股票名称 | `"雅克科技"` |
| `shares` | int | 持有股数 | `200` |
| `buy_price` | float | 买入均价（含手续费） | `151.348` |
| `current_price` | float | 最新价格（系统自动更新） | `155.900` |
| `stop_loss` | float | 当前止损价 | `140.00` |
| `highest` | float | 买入以来最高价 | `160.00` |
| `buy_date` | string | 买入日期 | `"2025-04-10"` |
| `reason` | string | 买入理由 | `"半导体材料龙头趋势买入"` |

### 2.3 更新持仓

当发生买入或卖出时，需要手动更新 `holdings.json`：

- **买入新股**：添加新的代码条目
- **卖出清仓**：删除对应代码条目
- **加仓/减仓**：修改 `shares` 和 `buy_price`（加权均价）
- **每日盘后**：`current_price` 由系统在分析时自动更新

> **注意**：`current_price` 会在每次运行分析时自动用最新收盘价更新，无需手动维护。

## 三、触发报告

### 3.1 命令行方式

所有报告通过 `run.py` 统一入口触发：

```powershell
# 盘后综合分析报告（技术分析+条件单+选股推荐）
python run.py report

# 生成次日条件单操作计划
python run.py orders

# 全赛道选股扫描
python run.py screen

# 操盘密码分析（DK信号+控盘生命线+资金流）
python run.py caopan

# 操盘密码3年回测
python run.py caopan --backtest

# 查看系统状态
python run.py status
```

### 3.2 直接运行各模块

```powershell
# 操盘密码报告
python caopan_report.py --morning    # 盘前作战计划
python caopan_report.py --evening    # 盘后深度复盘 + 条件单 + 预警
python caopan_report.py --weekly     # 周策略报告

# 条件单独立生成
python daily_orders.py

# 调度器
python scheduler.py                  # 启动常驻调度器
python scheduler.py --install        # 安装Windows定时任务
python scheduler.py --run-once       # 立即运行一次盘后分析

# 自动化守护进程
python auto_scheduler.py             # 常驻运行
python auto_scheduler.py --once      # 只执行一次盘后任务
```

### 3.3 典型工作流

| 时间 | 操作 | 命令 |
|------|------|------|
| 每晚 19:00 | 生成条件单 → 照抄到东方财富APP | `python run.py orders` |
| 每晚 19:05 | 查看综合分析报告 | `python run.py report` |
| 次日开盘 | 条件单自动触发，确认成交 | 无需操作 |
| 周末 | 查看周度回顾 | 自动发送（定时任务） |

## 四、解读邮件内容

系统发送的邮件报告包含以下面板：

### 4.1 盘前作战计划（08:30）

| 面板 | 内容 |
|------|------|
| 市场环境 | 大盘强度（强/震荡/弱）+ 总仓位上限建议 |
| 操作清单 | 每只持仓的操作建议（持有/减仓/止损） |
| 关键价位 | 支撑位、压力位、止损位、止盈位 |
| 仓位建议 | 当前仓位分布 + 再平衡建议 |

### 4.2 盘后综合日报（15:30）

| 面板 | 内容 |
|------|------|
| 操盘密码 | DK信号（D点买入/K点卖出）+ 信号强度评分 |
| 控盘生命线 | EMA快线/慢线 + 趋势分级（5级）+ 乖离率 |
| 资金流向 | 主力净流入/流出 + 大单占比 + 背离检测 |
| 筹码分布 | 获利盘比例 + 筹码密集峰 + 控盘度评分 |
| 板块分析 | 持仓所在板块动量排名 + 资金流向 |
| 多因子评分 | 技术+资金+动量+基本面的综合评分 |
| 持仓盈亏 | 各标的浮盈浮亏 + 市值统计 |
| K线图 | 60日K线 + 均线 + 买卖点标注 |

### 4.3 条件单（19:00）

| 面板 | 内容 |
|------|------|
| 持仓健康度 | 四级巡检：🔴危险/🟠预警/🟡关注/🟢健康 |
| 条件单清单 | 每条条件单的触发价/触发时间/数量/有效期 |
| 风控状态 | 总仓位/现金比例/仓位上限 |
| 纪律锁 | 今日禁止事项清单 |
| 新闻预警 | 持仓相关新闻风险提示（仅预警不影响信号） |

### 4.4 条件单优先级

| 优先级 | 标记 | 含义 |
|--------|------|------|
| ★★★必挂 | 红色标签 | 止损单/清仓单，必须设置 |
| ★★建议 | 橙色标签 | 止盈单/回落止盈，强烈建议设置 |
| ★可选 | 绿色标签 | 辅助性单据，视情况设置 |

## 五、条件单设置

### 5.1 使用方法

`daily_orders.py` 生成的条件单报告，照抄到东方财富APP：

1. 打开东方财富APP → 交易 → 智能条件单
2. 逐条添加条件单（按优先级顺序）
3. 确认触发价、触发时间、数量、有效期
4. 设置完成后，盘中不再操作

### 5.2 止损四档规则

系统根据持仓浮盈状态自动匹配止损档位：

| 浮盈状态 | 止损类型 | 止损价计算 | 触发时间 |
|----------|----------|------------|----------|
| 浮亏 | 浮亏保护 | 现价 × 92%（再跌8%离场） | 14:50 |
| 浮盈 < 5% | 初始止损 | 成本 × 90% | 14:50 |
| 浮盈 5%-15% | 保本止损 | 成本 × 102% | 14:50 |
| 浮盈 > 15% | 移动止盈 | 20日最高价 × 95% | 盘中实时 |

> **举例**：持仓招商银行，成本39.15元，现价37.36元（浮亏4.6%）
> - 止损类型：浮亏保护
> - 止损价 = 37.36 × 0.92 = 34.371元
> - 含义：如果再跌8%到34.371元，14:50尾盘确认卖出

### 5.3 特殊条件单

| 类型 | 触发条件 | 说明 |
|------|----------|------|
| 清仓条件单 | 空头趋势 + 浮亏>10% | 现价×97%，14:50触发，3日有效 |
| 回落止盈 | 多头趋势 + 浮盈>5% | 从最高点回落5%触发 |
| 强制减仓 | 空头趋势 + 有浮盈 | 卖出半仓，14:50触发 |

## 六、定时调度

### 6.1 方式一：Windows 任务计划（推荐）

```powershell
# 以管理员身份运行 PowerShell
python scheduler.py --install
```

自动创建以下定时任务：

| 任务名 | 时间 | 说明 |
|--------|------|------|
| `TradingSystem_ForecastAM` | 08:30 | 盘前作战计划 |
| `TradingSystem_Screener` | 09:25 | 竞价后选股 |
| `TradingSystem_Daily` | 15:30 | 盘后综合分析 |
| `TradingSystem_MorningReminder` | 19:00 | 条件单提醒 |
| `TradingSystem_Weekly` | 周六 10:00 | 周度回顾 |
| `TradingSystem_MLTraining` | 周六 11:00 | ML模型训练 |
| `TradingSystem_WalkForward` | 每月1日 09:00 | Walk-Forward验证 |

卸载所有任务：
```powershell
python scheduler.py --uninstall
```

### 6.2 方式二：常驻调度器

```powershell
python scheduler.py
```

前台常驻运行，按时间表自动执行所有任务。非交易时段自动降低检查频率（5分钟一次）。

### 6.3 方式三：轻量守护进程

```powershell
python auto_scheduler.py
```

简化版守护进程，仅管理3个核心任务：盘后条件单(15:30) + 分析报告(15:35) + 盘中QMT执行(09:25)。

## 七、常见问题排查

### 7.1 邮件发送失败

**现象**：报告生成成功但邮件未收到

**排查步骤：**
1. 检查 `EMAIL_AUTH_CODE` 环境变量是否设置
2. 检查 QQ 邮箱是否开启了 SMTP 服务
3. 确认授权码未过期（QQ邮箱授权码有效期约3个月）
4. 检查收件箱的"垃圾箱"文件夹
5. 查看日志中的具体错误信息：

```powershell
# 查看今日调度日志
type trading_system\logs\scheduler_20260725.log | Select-String "邮件"
```

### 7.2 数据获取异常

**现象**：分析报告中部分股票数据缺失

**排查步骤：**
1. 检查网络连接
2. baostock 有时限流，等待几分钟后重试
3. 清除本地缓存重新拉取：

```powershell
# 备份后删除本地数据库
# 系统会自动重新拉取
Remove-Item trading_system\data\stock_db.db
python run.py report
```

4. 检查 baostock 服务器状态：

```powershell
python -c "import baostock as bs; print(bs.login())"
```

### 7.3 持仓名称显示为代码

**现象**：报告中股票名称显示为6位代码而非中文名称

**原因**：`holdings.json` 中缺少 `name` 字段

**修复**：确保 `holdings.json` 中每条记录都有 `name` 字段。系统会优先从 `holdings.json` 查找名称，其次从 `config.py` 的 `STOCK_POOL` 和 `SECTOR_CANDIDATES` 查找。

### 7.4 风控状态异常

**现象**：明明没有亏损却被暂停开仓

**排查**：检查风控状态文件：

```powershell
type trading_system\output\risk_state.json
```

如果 `pause_until` 有日期且未过期，说明之前触发了连续亏损熔断。可以手动清除（将 `pause_until` 改为空字符串）或等待自动解禁。

### 7.5 条件单价格异常

**现象**：止损价高于现价

**说明**：系统有自动价格校验机制。当计算出的止损价≥现价时，会自动调整为 `现价 × 95%`，并在报告中注明"(调整)"。这是正常行为，常见于刚买入即下跌的情况。

### 7.6 控制台编码问题（Windows）

**现象**：PowerShell 输出乱码

**修复**：

```powershell
# 临时修复
chcp 65001

# 或设置 PowerShell 默认编码
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```
