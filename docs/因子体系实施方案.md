### 1.1 数据层补建

#### 1.1.1 基本面数据入库（SQLite）

**目标**: 将FundamentalAnalyzer的缓存数据持久化到SQLite，供factors/层直接查询。

**新建表**:
```sql
CREATE TABLE IF NOT EXISTS fundamental (
    code        TEXT NOT NULL,
    report_date TEXT NOT NULL,    -- 报告期 如"2026-06-30"
    update_date TEXT NOT NULL,    -- 数据更新日期
    pe_ttm      REAL,
    pb          REAL,
    roe         REAL,

    debt_ratio  REAL,

    net_profit_growth REAL,

);
```

**修改文件**:
- `data/data_loader.py`: 新增 `load_fundamental(code)` / `save_fundamental_batch(data_dict)`

### 2.3 日内成交量分布因子（暗流因子）

**文件**: `factors/volume_distribution.py`（新建）

```python
def calc_volume_distribution(code, minute_df, window=20):
    """
    暗流因子 - 日内成交分布的信息密度

    构造:
    1. 将每日分钟成交量归一化为分布
    2. 计算香农熵: H = -Σ p_i * log(p_i)
    3. 流动性弹性: 价格冲击/成交量变化的滚动回归
    4. 因子 = 0.5 * 熵标准化 + 0.5 * 弹性标准化

    数据: minute_kline 表（5分钟频率即可近似）
    方向: 正向（分布越均匀、缓冲能力越强越好）
    预期: 月度RankIC≈-7.65%, 多空年化29%
    """
```

### 2.4 低波动因子（独立化）

```python
def calc_low_volatility(df, window=20):
    """
    低波动因子

    构造:
    1. vol_20d = std(daily_return, 20)
    2. vol_60d = std(daily_return, 60)
    3. max_dd_20d = 近20日最大回撤

    5. 因子 = -(0.4*vol_20d + 0.3*vol_60d + 0.2*max_dd + 0.1*beta)

    方向: 正向（低波动得分高 = 波动率低）
    """
```

## 七、风险与注意事项

1. **过拟合**: 因子参数需 walk_forward 检验，不可全样本优化
2. **前瞻偏差**: 基本面数据必须用发布日（非报告期），避免look-ahead bias
3. **数据质量**: 极端值/停牌/新股需统一处理（preprocessor四步法）
4. **计算成本**: 全因子截面计算建议增量更新（非全量重算）
5. **因子拥挤**: 定期检查因子相关性矩阵，IR>0.7的因子对需正交化
6. **回测验证**: 每个因子改动必须走"基线→改动→对比"验证规范
