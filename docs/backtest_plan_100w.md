## 三、策略选择与权重分配

### 3.1 核心策略：趋势波段策略（权重 100%）

本系统唯一周期定位为 **3日-4周中线波段**，回测使用系统默认趋势策略 `trend_strategy.default_strategy()`：

| 信号类型 | 条件 | 来源函数 |
|----------|------|----------|
| **买点1: 缩量回踩MA20** | 量缩30%+触及MA20±1%+均线多头 | `check_buy_signal()` |
| **买点2: 放量突破回踩确认** | 突破后缩量回踩+量价配合 | `check_breakout_buy_signal()` |
| **质量分门槛** | 综合评分≥62分（非熊市） | `generate_strategy_signal()` |
| **双买点共振** | 买点1+买点2同时满足→信号增强 | `scan_all_stocks()` |

### 3.2 卖出信号优先级（从高到低）

| 优先级 | 卖出条件 | 阈值 | 来源 |
|--------|---------|------|------|
| 1 | 单日放量大跌 | >8%+量比>2 | `check_sell_signal()` |
| 2 | 收盘跌破移动止损 | 阶梯上移 | `compute_trailing_stop()` |
| 3 | 跌破60日线+均线拐头 | MA60破位 | `check_sell_signal()` |
| 4 | MACD死叉（盈利状态） | DIF<DEA | `check_sell_signal()` |
| 5 | 从最高点回落 | 龙头8%/成长7%/弹性6% | `check_sell_signal()` |

### 3.3 移动止损阶梯

| 浮盈区间 | 止损位 | 含义 |
|---------|--------|------|
| 0~3% | 买入价×0.90 | 初始保护（亏10%走人） |
| 3%~15% | 买入价×1.01 | 保本+1% |
| 15%~30% | 买入价×1.12 | 锁定12%利润 |
| >30% | 买入价×1.22 | 锁定22%利润 |

### 3.4 阶梯止盈

| 浮盈阈值 | 操作 |
|---------|------|
| +18% | 卖出 1/4 |
| +25% | 卖出 1/3 |

## 四、因子体系

### 4.1 参与回测的因子清单

回测引擎通过 `FactorRegistry` 自动加载已注册因子，按 IC 动态调权：

| 类别 | 因子 | 方向 | 默认权重 |
|------|------|------|----------|
| **技术** | MA乖离率(20日) | -1 | 1.0 |
| **技术** | MACD金叉/死叉 | 1 | 1.0 |
| **技术** | RSI(14) | -1 | 1.0 |
| **技术** | 布林位置 | -1 | 1.0 |
| **技术** | ATR(14) | -1 | 1.0 |
| **量价** | OBV趋势 | 1 | 1.0 |
| **量价** | VWAP乖离 | -1 | 1.0 |
| **量价** | 量比(5/20) | 1 | 1.0 |
| **量价** | MFI | 1 | 1.0 |
| **动量** | 20日收益率 | 1 | 1.0 |
| **动量** | 60日收益率 | 1 | 1.0 |
| **动量** | 加速度 | 1 | 1.0 |
| **量价** | 聪明钱(smf_proxy) | 1 | 1.0 |
| **量价** | 改进反转(improved_reversal) | 1 | 1.0 |
| **低波** | 低波动(low_volatility) | 1 | 1.0 |

### 4.2 因子合成方式

- **预处理**: 去极值(MAD) → 标准化(Z-score) → 中性化(市值/行业)
- **合成**: IC加权合成（IC持续<-0.02的因子自动降权至0）
- **调权频率**: 每月更新一次权重（20个交易日）

## 五、风控规则

### 5.1 仓位管理（`RISK_UNIFIED_CONFIG`）

| 规则 | 阈值 | 效果 |
|------|------|------|
| 最大持仓数 | 8 只 | 超限禁止新开仓 |
| 单票上限 | 个股15% / ETF20% | 超限禁止加仓 |
| 赛道上限 | 40% | 超限禁止该赛道加仓 |
| 最低现金 | 10% | 可用<10%禁止新开仓 |
| 总仓位闸门 | 指数>MA20→80%, <MA20→50%, <MA60→30% | 动态调整总仓位上限 |

### 5.2 止损体系

| 层级 | 参数 | 说明 |
|------|------|------|
| 初始止损 | -10% | 买入价下方10% |
| ATR自适应止损 | 2.5×ATR, 范围[5%, 15%] | 收盘确认模式 |
| 梯度减仓 | -9%→减1/3, -12%→减1/2, -15%→清仓 | 三档递进 |
| 回撤渐进降仓 | -5%→80%, -8%→60%, -12%→30% | 浮亏越深仓位越低 |
| 深亏模式 | ≤-30% | 每日1条汇总提醒 |

### 5.3 大盘门控

| 级别 | 沪深300跌幅 | 效果 |
|------|------------|------|
| L0 正常 | >-0.5% | 正常交易 |
| L1 走弱 | ≤-0.5% | 买点降级标记 |
| L2 走跌 | ≤-1.5% | 暂停买入 |
| L3 暴跌 | ≤-2.5% | 禁止一切买入 |

### 5.4 反冲动锁

| 锁 | 触发条件 | 效果 |
|----|----------|------|
| 集中度锁 | 单票>15%(ETF>20%) | 禁止加仓 |
| 亏损锁 | 当日跌>3% | 当日禁止加仓 |
| 深套锁 | 浮亏>8% | 回本前禁止加仓 |
| 系统性风险锁 | 沪深300跌>1.5% | 暂停一切买入 |

## 六、执行流程

```
┌──────────────────────────────────────────────────────────────┐
│  每个交易日循环                                                │
│                                                              │
│  DataFeed.get_bar(date)                                      │
│       ↓                                                      │
│  compute_indicators(df)  ← 截至昨日数据（防未来函数）          │
│       ↓                                                      │
│  FactorRegistry.compute_all(df)  ← 因子矩阵                  │
│       ↓                                                      │
│  trend_strategy.generate_strategy_signal(df, holding)        │
│       ↓                                                      │
│  ┌─ 买入信号 ─→ RISK_UNIFIED_CONFIG 仓位校验 ─→ 大盘门控     │
│  │              → 反冲动四把锁 ─→ SimBroker.submit_order()    │
│  │                                                          │
│  ├─ 卖出信号 ─→ SimBroker.submit_order() (T+1检查)           │
│  │                                                          │
│  └─ 无信号   ─→ 持仓观望                                     │
│       ↓                                                      │
│  SimBroker.match_orders()  ← A股规则撮合                     │
│       ↓                                                      │
│  记录净值 → 下一交易日                                         │
└──────────────────────────────────────────────────────────────┘
```

## 八、报告指标清单

### 8.1 收益指标

| 指标 | 计算方式 | 基准 |
|------|----------|------|
| 总收益率 | (期末净值-期初净值)/期初净值 | — |
| 年化收益率 | (1+总收益)^(252/交易日数)-1 | — |
| 超额收益(α) | CAPM回归截距 | 沪深300 |
| Beta | CAPM回归斜率 | 沪深300 |
| 信息比率 | α / 跟踪误差 | 沪深300 |

### 8.2 风险指标

| 指标 | 计算方式 | 合格线 |
|------|----------|--------|
| 最大回撤 | max(peak-trough)/peak | <25% |
| 夏普比率 | (年化收益-3%)/年化波动率 | >1.0 |
| 卡尔马比率 | 年化收益/最大回撤 | >1.0 |
| Sortino比率 | (年化收益-3%)/下行波动率 | >1.5 |
| 年化波动率 | std(日收益)×√252 | — |
| VaR(95%) | 日收益5%分位数 | — |

### 8.3 交易统计

| 指标 | 说明 |
|------|------|
| 总交易笔数 | 完整买卖为一笔 |
| 胜率 | 盈利笔数/总笔数 |
| 盈亏比 | 平均盈利/平均亏损 |
| 平均持仓天数 | 持仓周期均值 |
| 最大连亏笔数 | 连续亏损交易次数 |
| 最大连亏天数 | 连续亏损交易日数 |

### 8.4 归因分析

| 维度 | 方法 | 模块 |
|------|------|------|
| Alpha/Beta | CAPM回归 | `attribution/alpha_beta.py` |
| Brinson三效应 | 配置AR+选股SR+交互IR | `attribution/brinson.py` |
| 夏普分解 | Beta收益 vs Alpha收益 vs 主动风险 | `attribution/sharpe_decompose.py` |
| 风格因子 | MKT/SMB/HML/MOM/REV/VOL/LIQ | `attribution/style_factors.py` |

### 8.5 稳健性检验

| 维度 | 方法 | 模块 |
|------|------|------|
| 参数敏感性 | 网格扫描+高原检测 | `param_plateau.py` |
| 样本外泛化 | Walk-Forward滚动 | `walk_forward.py` |
| 极端场景 | Monte Carlo + 历史回放 | `monte_carlo.py` |
| 多重检验 | Deflated Sharpe/PBO | `deflated_sharpe.py` |
| 成本敏感 | 四档成本阶梯 | `cost_sensitivity.py` |
| 市场分段 | 牛/熊/震荡分段表现 | `regime_segments.py` |
| 双引擎交叉 | V2 vs V5 对比 | `engine_crosscheck.py` |
| 对抗探针 | 8大红队测试 | `red_team_probes.py` |
