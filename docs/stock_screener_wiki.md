## 1. 策略概述

### 1.1 定位

本选股体系是面向A股个人投资者的**中线波段选股系统**，融合William O'Neil经典CANSLIM方法论与A股实战适配，目标是在控制风险的前提下捕捉趋势启动和主升浪行情。

### 1.2 核心参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 目标胜率 | 60-65% | 回测验证V5.0实际胜率61.8% |
| 持仓周期 | 3天-4周 | 中线波段，非日内/超短 |
| 最大持仓数 | 7只 | 已验证最优（config.MAX_HOLDINGS） |
| 单笔最大风险 | 总资金2% | RISK_UNIFIED_CONFIG.max_single_loss_ratio |
| 最低盈亏比 | 2.5:1 | 不达标直接拦截 |
| 初始止损 | 10% | 买入价×90%（固定百分比兜底） |
| 适用市场 | 沪深主板 | 排除创业板(300)/科创板(688)，无交易权限 |

### 1.3 适用市场环境

- **最佳**: 沪深300在MA20/MA60上方，MA20斜率向上（满仓操作）
- **可做**: 沪深300在MA20上方但MA20<MA60（半仓操作）
- **谨慎**: 沪深300跌破MA20但在MA60上方（轻仓30%）
- **停止**: 沪深300跌破MA20和MA60（不建议买入，仅输出观察）

### 2.3 三引擎并行（V3.2升级）

系统包含三套独立选股引擎，适用不同场景：

| 引擎 | 文件 | 评分体系 | 适用场景 |
|------|------|----------|----------|
| CANSLIM选股引擎 | `stock_screener.py` | N/S/L/CAI/P 五因子(0-100) | 盘后深度选股、次日建仓 |
| 五层推荐引擎 | `recommend_engine.py` | 排雷→赛道→基本面→趋势→买点 | 盘前观察池、个股诊断 |
| **短线动量筛选** | `stock_screener.py → run_momentum_screener()` | 涨幅30+量比25+换手20+连板15+成交额10 | 盘中强势股捕捉、短线机会 |

> **V3.2变更说明**：原"双引擎并行"升级为"三引擎并行"。短线动量筛选与CANSLIM并行运行，
> 增量输出不影响CANSLIM主流程。在`caopan_report.py --screener`和盘中预警中均可触发。

### 2.4 双模式运行

| 模式 | 触发方式 | 数据源 | 侧重点 |
|------|----------|--------|--------|
| 盘中实时 | `caopan_report.py --screener`（手动） | baostock + 腾讯实时API | 当日异动捕捉、实时评分、动量筛选 |
| 盘后深度 | `report_dispatcher.py --evening` / `main.py` Step 9 | baostock收盘数据 + akshare全市场扫描 | 完整五层分析、次日计划 |

### 2.5 短线动量筛选通道（V3.2新增）

`stock_screener.py` 的 `run_momentum_screener()` 函数实现独立的短线动量筛选：

**评分体系（0-100分）**：

| 维度 | 满分 | 评分规则 |
|------|------|----------|
| 涨幅 | 30分 | ≥7%得30，5-7%得20，3-5%得10 |
| 量比 | 25分 | ≥3得25，2-3得18，1.5-2得10 |
| 换手率 | 20分 | 5-15%得20，3-5%得12 |
| 连板 | 15分 | 2连板15，首板10 |
| 成交额 | 10分 | ≥10亿得10，5-10亿得6 |

**硬过滤规则**：
- 排除创业板(300)/科创板(688)：无交易权限
- 排除ST股、价格>500元
- 一字板检测：`open_price >= limit_price * 0.998` → 标记"一字板-不可买"
- 价格区间：3-300元

**输出格式**：
```python
{
    "success": True,
    "picks": [{"code", "name", "change_pct", "vol_ratio", "momentum_score", "sector", "is_yizi", "t1_note"}],
    "summary": "共扫描N只，筛出M只强势股"
}
```

**调用入口**：
- `caopan_report.py --screener`：CLI选股流程中自动运行（涨停基因之后、邮件发送之前）
- `intraday_alert.py`：盘中双通道扫描联动

### 2.6 双通道盘中扫描（V3.2新增）

`intraday_alert.py` 的 `_run_screener_intraday()` 实现双通道扫描：

| 通道 | 扫描范围 | 阈值 | 目的 |
|------|----------|------|------|
| 通道A | 赛道候选池内 | 涨≥2% + 量比≥1.5 + 成交额≥2亿 | 池内低阈值捕捉启动信号 |

## 3. 评分因子详解

### 3.1 CANSLIM引擎因子（stock_screener.py）

总分 = N + S + L + CAI + P + W，满分105分（基础100 + W周线±5）

| 因子 | 满分 | 数据来源 | 核心计算逻辑 |
|------|------|----------|--------------|
| **N（新事物/新高）** | 20分 | 技术面 | 创60日新高+12, 创120日新高+8, 距新高<5%+5, 已突破+8 |
| **S（供需/量价）** | 20分 | 技术面 | ★缩量回踩MA20不破+20, 放量突破新高+10, 下跌缩量+5 |
| **L（领涨龙头）** | 20分 | 技术面 | RPS前20%+12, 60日涨幅>30%+8, 20日温和上涨+5 |
| **CAI（基本面）** | 20分 | FundamentalAnalyzer | 季度增速>50%+8, 3年复合>30%+7, 机构持仓+5 |
| **P（前瞻性）** | 20分 | 技术面 | 动量延续6分+板块轮动5分+突破预判5分+量能蓄积4分 |
| **W（周线共振）** | ±5分 | 技术面 | MA50方向向上且价格>MA50→+5, MA50向下且价格<MA50→-5 |

#### N因子得分细则（20分）

**强势市（market_state=up）：**

| 条件 | 得分 | 说明 |
|------|------|------|
| 创60日新高 | +12 | 收盘价≥近60日最高价×0.98 |
| 创120日新高 | +8 | 收盘价≥近120日最高价×0.98（与60日叠加） |
| 距60日新高<5% | +5 | 接近突破 |
| 已突破60日新高 | +8 | 确认突破 |

**V2.7 震荡市适配（market_state=neutral/down/weak）：**

| 条件 | 得分 | 说明 |
|------|------|------|
| 创60日新高 | +12 | 同强势市 |
| 创120日新高 | +8 | 同强势市 |
| 距20日高点<3% | +8 | V2.7新增：震荡市放宽，避免N因子系统性归零 |
| 距20日高点<5% | +5 | V2.7新增：次级接近 |
| 距60日新高<5% | +5 | 同强势市 |
| 已突破60日新高 | +8 | 同强势市 |

> **V2.7设计理由**: 震荡市中94%股票无法创60日新高，导致N因子系统性归零。新增"距20日高点"条件让相对强势股也能获得部分N分。

#### S因子得分细则（20分）

| 条件 | 得分 | 说明 |
|------|------|------|
| ★缩量回踩MA20不破 | +20 | vol_ratio<0.7 + low≤MA20×1.01 + close>MA20 |
| 缩量回踩MA20 | +16 | vol_ratio<0.7 + 距MA20在-3%~+2% |
| 放量突破新高 | +10 | vol_ratio>1.5 + 创60日新高 + 收阳 |
| 放量上涨 | +6 | vol_ratio>1.5 + 收阳 |
| 下跌缩量 | +5 | 收阴但量比<0.6 |

#### L因子得分细则（20分）

| 条件 | 得分 | 说明 |
|------|------|------|
| RPS前10% | +20 | 全市场60日涨幅排名前10% |
| RPS前20% | +12 | 全市场60日涨幅排名前20% |
| RPS前30% | +8 | 全市场60日涨幅排名前30% |
| 60日涨幅>30% | +8 | 绝对涨幅强势 |
| 20日温和上涨(5-20%) | +5 | 非暴涨暴跌 |

#### CAI因子得分细则（20分）

| 条件 | 得分 | 说明 |
|------|------|------|
| 单季度EPS增速>50% | +8 | 高增长 |
| 单季度EPS增速>25% | +5 | 中高增长 |
| 单季度EPS增速>0% | +2 | 正增长 |
| 3年复合增速>30% | +7 | 长期成长性强 |
| 3年复合增速>15% | +4 | 稳定增长 |
| 机构持仓>10% | +5 | 机构认可 |

> **V2.7规则（替代V2.3-P0）**: 无有效基本面数据时（三个字段均无正向信号），CAI给中性基础分8分。有正向数据时按实际计算（可高于或低于8分）。避免股票因数据全零而天然少20分。

#### P因子得分细则（20分）

| 维度 | 满分 | 判断逻辑 |
|------|------|----------|
| 动量延续性 | 6分 | 近5日≥4天上涨且加速 → 明日延续概率高 |
| 板块轮动预判 | 5分 | 近5日贡献20日涨幅>70% → 板块刚启动 |
| 突破预判 | 5分 | 距20日新高<2% → 明日可能突破 |
| 量能蓄积 | 4分 | 近5日量比1.2-2.0且价涨 → 主力吸筹 |

#### W因子（周线共振，V2.3-P1）

| 条件 | 得分 | 说明 |
|------|------|------|
| MA50方向向上 且 收盘价>MA50 | +5 | 周线级别多头共振 |
| MA50方向向下 且 收盘价<MA50 | -5 | 周线级别空头共振 |
| 其他情况 | 0 | 不加分不减分 |

> 计算方式：MA50_now vs MA50_5日前，判断方向；需至少55个交易日数据。

### 3.2 五层推荐引擎因子（recommend_engine.py）

综合评分 = 赛道×20% + 基本面×15% + 趋势×40% + 买点×25%

| 层级 | 权重 | 评分范围 | 核心指标 |
|------|------|----------|----------|
| 第1层 排雷 | 一票否决 | 通过/不通过 | 流动性≥3亿、非ST、非庄股、无暴跌 |
| 第2层 赛道 | 20% | 0-100 | 60日涨幅、均线多头、MA20斜率 |
| 第3层 基本面 | 15% | 0-100 | ROE、业绩增速、价格分位 |
| 第4层 趋势 | 40% | 0-100 | 均线系统30分+MACD20分+RSI15分+量能20分+RPS15分 |
| 第5层 买点 | 25% | 0-100 | 盈亏比≥2.5+40分、买点类型+30分、缩量+15分 |

### 3.3 输出规则与买入推荐分界线（V2.7动态化）

```python
# V2.7: 买入线根据大盘状态动态调整
min_buy_score_weak = 35     # 弱势/震荡市买入线（market_state=down/weak/neutral）
min_buy_score_strong = 50   # 强势市买入线（market_state=up）
min_score = 40              # 仅作排序参考，不再淘汰
total_max = 10              # 每天固定输出评分最高的10只

# 判定逻辑：
评分 ≥ 动态买入线 → 标记"推荐买入"，生成完整买点计划（三档买点+止损+仓位）
评分 < 动态买入线 → 标记"仅观察"，不生成买入计划，仅展示评分和趋势状态

# 允许10只全部为"仅观察"（即当天无买入推荐）
# 邮件报告中明确提示："本期无符合买入条件的标的，以下仅供跟踪观察"
```

> **V2.7设计理由**: 震荡市中N因子几乎归零，固定50分买入线等于要求77%可达分，导致永远0推荐。动态化后震荡市降至35分，确保有选择性推荐。

#### 排序规则

1. 所有候选股按 total_score 降序排列
2. 取前10只（跳过已持仓股）
3. 行业配额仅对“推荐买入”级别生效（单赛道最多3只），观察级不受配额限制
4. 配额已满时，该股降级为“仅观察”

#### 硬性筛选层（保留不变）

| 筛选项 | 参数 | 说明 |
|--------|------|------|
| 成交额门槛 | ≥5亿 | V2.4从8亿降至5亿，避免中小盘龙头被误杀 |
| ST/退市过滤 | 硬过滤 | 包含DELISTED_STOCKS黑名单 |
| 冷却期 | 1天 | V2.7: 从2天缩短为1天，冷却期股仍参与评分但标注"达标但冷却中" |
| 均线多头排列 | 强势模式必须 | MA5>MA10>MA20 |
| 弱势模式 | weak_score≥25 | 大盘下跌时放宽 |

#### 邮件报告结构（V2.4）

| 板块 | 内容 |
|------|------|
| 一、赛道强弱排名 | 各赛道综合评分、20日涨跌、加速度 |
| 二、推荐买入 | 评分≥50分的股票，附买点计划+因子明细 |
| 三、观察跟踪 | 评分<50分的股票，仅展示评分+因子+观察原因 |
| 操作指南 | CANSLIM体系+分批建仓说明 |

## 4. 买点与卖点规则

### 4.1 买入信号类型

| 信号 | 触发条件 | 评分加成 | 优先级 |
|------|----------|----------|--------|
| ★缩量回踩MA20不破 | vol_ratio<0.7 + low≤MA20×1.01 + close>MA20 | S因子+20 | 最高（核心买点） |
| 缩量回踩MA20 | vol_ratio<0.7 + 距MA20在-3%~+2% + close>MA20 | S因子+16 | 高 |
| 放量突破新高 | vol_ratio>1.5 + 创60日新高 + 收阳 | S因子+10 | 高 |
| 放量上涨 | vol_ratio>1.5 + 收阳（未创新高） | S因子+6 | 中 |
| 横盘突破启动 | 20日横盘后5日涨>3% | P因子+4 | 中 |
| 动量加速 | 近5日≥4天上涨且加速 | P因子+6 | 中 |

### 4.2 三档买点价格

| 买点 | 计算方式 | 适用场景 |
|------|----------|----------|
| 激进买点 | 回踩信号→现价; 突破信号→现价×1.005 | 信号明确时追入 |
| 稳健买点 | max(MA5, MA10) × 1.005 | 默认推荐 |
| 保守买点 | MA20 × 1.005 | 等待回调 |

### 4.3 分批建仓方案

```
第一批 40%: 在稳健买点附近建仓（试仓）
第二批 60%: 浮盈≥3%后加仓（确认趋势）
加仓触发价 = 稳健买点 × 1.03
```

### 4.4 卖出信号类型

| 信号 | 触发条件 | 动作 |
|------|----------|------|
| 固定止损 | 亏损达买入价×90%（-10%），盘中low触发 | 无条件止损 |
| ATR止损 | 价格 < 买入价 - 2×ATR（龙头）/ 2.5×ATR（弹性），low触发 | 止损 |
| 技术支撑止损 | 跌破MA20×0.99 或 MA60×0.99 | 止损 |
| 移动止损 | 浮盈后上移（保护利润） | 止盈 |
| 时间止损 | 持仓>20天且浮盈<5%（V7.1新增） | 强制清仓 |
| 趋势破坏 | 浮亏>10% + 跌破MA20 | 减仓50% |
| 深度止损 | 浮亏>15% | 无条件清仓 |
| 中期走坏 | 跌破MA60 + 浮亏 | 减仓 |

## 5. 风控体系

### 5.1 个股止损（三重保护）

```python
# 取三者中最高价（最保守），但不超过现价×95%
final_stop = max(ATR止损, 技术支撑止损, 固定10%止损)
final_stop = min(final_stop, current_price × 0.95)  # 最多5%以内

# ATR止损
atr_stop = price - 2.0 × ATR  # 龙头
atr_stop = price - 2.5 × ATR  # 弹性标的

# 技术支撑止损
support_stop = max(MA20 × 0.99, MA60 × 0.99)  # 取较高者
```

### 5.2 组合风控

| 规则 | 参数 | 来源 |

## 7. 策略诊断与优化建议

### 7.1 当前薄弱环节诊断

#### 问题1: CAI基本面因子有效性不足（V2.7已修复）

**现状**: CAI因子满分20分，`FundamentalAnalyzer`通过akshare获取数据。V2.7起，无有效正向数据时给中性基础分8分（替代V2.3的"不给分"规则）。

**已修复内容(V2.7)**:
- 无有效数据（三字段均无正向信号）→ CAI=8分（中性）
- 有正向数据 → 按实际计算（可高于或低于8分）
- 解决了63%股票因数据全零而天然少20分的问题

**待优化方向**: 
- 增加akshare重试机制（当前失败即跳过）
- 预期效果: 减少因基本面恶化导致的止损，胜率+1-2%

#### 问题2: RPS排名仅在候选池内计算

**现状**: L因子的RPS排名是在`data_dict`（最多55只）内计算，而非全市场5000+只A股。

**影响**: RPS前20%在55只中的含金量远低于全市场，可能高估个股相对强度。

**优化方向**:
- 利用`scan_market_hot_stocks()`返回的全市场涨跌幅数据计算真实RPS
- 或使用akshare的`stock_zh_a_spot_em()`获取全市场60日涨幅做排名
- 预期效果: L因子区分度提升，减少"矮子里拔将军"，胜率+1%
- 实施难度: 中

#### 问题3: 候选池赛道覆盖存在盲区

**现状**: 8大赛道29只静态候选，缺少当前市场热门赛道（如机器人、低空经济、数据要素等）。

**影响**: 当新赛道爆发时系统完全无法捕捉。

**优化方向**:
- 动态扫描已接入（V2.2），但仅取综合评分前15只，无赛道标签
- 建议: 为动态扫描结果自动匹配行业分类（akshare有行业字段）
- 每月手动审视SECTOR_CANDIDATES，淘汰弱势赛道补充新兴赛道
- 预期效果: 覆盖面从29只扩大到40-55只，减少赛道盲区
- 实施难度: 低（手动）/ 中（自动行业分类）

#### 问题4: 买点信号缺乏多周期共振验证

**现状**: 买点判断仅基于日线级别（MA20回踩/60日新高），无周线确认。

**影响**: 日线级别假突破/假回踩较多，导致买入后短期被套。

**优化方向**:
- 增加周线MA10/MA30方向确认（周线向上时日线买点才有效）
- 在`canslim_score()`中增加周线共振加分（+5分）
- 预期效果: 过滤30%假信号，胜率+2-3%
- 实施难度: 中（需baostock拉取周线数据）

#### 问题5: 止损后冷却期执行保障（V2.7已修复）

**现状**: V2.7已实现冷却期优化：
- 冷却期从2天缩短为1天（SCREENER_CONFIG["cooldown_days"]=1）
- 冷却期股票仍参与评分，但评分达标时标注"达标但冷却期中"而非直接消失
- 报告中明确显示冷却期状态，避免唯一达标股"自废武功"

**待优化方向**:
- 可考虑根据止损原因区分冷却时长（技术止损1天 vs 基本面止损3天）

### 7.2 优化优先级排序

| 优先级 | 优化项 | 预期胜率提升 | 实施难度 | 状态 |
|--------|--------|-------------|----------|------|

## 附录D: V2.4增强功能说明

### D.1 动态扫描重试机制

**问题**: `scan_market_hot_stocks()` 调用akshare接口时，网络抖动直接导致整个扫描失败。

**解决方案**:

```python
# 重试策略: 最多3次，每次间隔2秒
for attempt in range(1, max_retries + 1):
    try:
        df = ak.stock_zh_a_spot_em()
        if df is not None and not df.empty:
            break
    except (ConnectionError, TimeoutError, OSError):
        time.sleep(2)  # 等待2秒后重试

# 重试全部失败 → 缓存降级（有效期24小时）
if df is None:
    cache_data = _get_scan_cache()  # 使用上次成功结果
    if cache_data:
        cache_data["from_cache"] = True
        return cache_data
```

| 参数 | 值 | 说明 |
|------|-----|------|
| max_retries | 3 | 最大重试次数 |
| 重试间隔 | 2秒 | 每次失败后等待 |
| 缓存有效期 | 24小时 | 超时后缓存失效 |

### E.2 盘中异动监测 V2.6 (intraday_alert.py)

**功能**: 全市场实时扫描，五大检测维度并行运行。

**检测维度一: 准涨停股(涨幅≥7%)**
- 涨幅 >= 7% (ALERT_MIN_CHANGE_PCT)
- 量比 >= 1.5 (ALERT_MIN_VOL_RATIO)
- 成交额 >= 3亿 (ALERT_MIN_AMOUNT)
- 股价 3-300元区间，排除ST/退市/次新
- 封板概率估算(0-95%)

**检测维度二: 放量突破启动(3-7%) [V2.6新增]**
- 涨幅 3-7% (ALERT_BREAKOUT_MIN_CHANGE ~ MAX_CHANGE)
- 量比 >= 2.0 (ALERT_BREAKOUT_MIN_VOL_RATIO)
- 成交额 >= 2亿 (ALERT_BREAKOUT_MIN_AMOUNT)
- 突破强度评分(0-100): 涨幅(30)+量比(35)+换手率(20)+成交额(15)
- 与准涨停互补: 发现“正在启动”而非“快涨停”的强势股

**检测维度三: 板块联动预警**
- 同板块涨停数 >= 2 (ALERT_SECTOR_CASCADE_THRESHOLD)
- 跟涨候选涨幅 5-9%

**检测维度四: 涨停基因联动 [V2.6新增]**
- 与zt_gene_tracker联动，复用昨日涨停池数据
- 昨日涨停 + 今日高开>3% + 量比>2 = 连板启动信号

**检测维度五: 选股引擎盘中推荐 [V2.6新增]**
- 从SECTOR_CANDIDATES赛道候选池中筛选
- 涨幅>2% + 量比>1.5 + 成交额>2亿
- 轻量级快速过滤(不运行完整五层筛选)

**首次触发即时推送 [V2.6新增]**:
- 同一标的当日首次满足条件时立即推送
- 后续轮次不重复推送(ALERT_FIRST_TRIGGER_ONLY=True)
- 每日自动重置跟踪集合

### E.3 涨停基因跟踪 (zt_gene_tracker.py)

**功能**: 跟踪昨日涨停股今日表现，识别连板候选。

**跟踪流程**:
1. 获取昨日涨停池 (akshare `stock_zt_pool_em`)
2. 获取这些股票今日实时行情
3. 筛选高开>3% + 量比>2 的连板候选
4. 按连板概率排序输出

**配置参数** (`config.py`):

| 参数 | 默认值 | 说明 |
|------|--------|------|
| ZT_GENE_ENABLED | True | 是否启用涨停基因跟踪 |
| ZT_GENE_MIN_OPEN_PCT | 3.0 | 连板候选最低高开幅度(%) |
| ZT_GENE_MIN_VOL_RATIO | 2.0 | 连板候选最低量比 |
| ZT_GENE_TRACK_DAYS | 3 | 跟踪最近N天涨停股 |

### E.4 持仓深度预警 (alert_engine.py) [V2.6新注册]

### E.6 降级策略

所有模块均遵循“静默降级”原则：
- akshare调用失败 → logger.warning + 返回空结果
- 网络超时 → 重试2次后降级
- 非交易时间 → 跳过执行
- 数据为空 → 输出提示信息，不中断主流程
- 涨停基因/选股引擎联动失败 → 不影响其他检测维度
