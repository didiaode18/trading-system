# 证据分级研究 + 事件催化剂双分级 Skill

## 背景与定位
系统报告与 `news_monitor.py`、`event_calendar.py` 当前只做信息罗列，缺少"AI 该按什么规则下结论"的总控层。本技能把投研纪律工程化：**强制区分事实、推断与假设，强制标注来源，强制并列正反证据；事件与受益标的双分级，传闻与概念不进交易决策。**

## 实施路径
```
trading_system/research/
├── __init__.py
├── evidence_tags.py     # 证据等级定义与标签渲染（L1/L2/L3 统一格式）
├── claim.py             # 结论对象 Claim（结论文本+等级+报告期+来源+正反证据）
├── validator.py         # 报告输出校验：无来源/无标签/无反证的结论不得输出
├── catalyst.py          # 事件催化剂分级（事件证据等级 × 标的受益等级）
└── report_section.py    # 证据分级版报告区块（先做一个样板，再推广）
```

## 一、证据三级标注规范（适用于系统全部文字结论）
| 标签 | 含义 | 允许的来源 |
|---|---|---|
| `[事实·L1]` | 可核验的客观数据/已发生事件，必须注明报告期、发布日期、来源 | 公司公告/定期报告、交易所、官方统计、权威行情接口 |
| `[推断·L2]` | 基于 L1 数据的逻辑推理，必须写明推理链条，且给出置信度 | 由 L1 数据计算/对比得出 |
| `[假设·L3]` | 尚未证实的判断/预测，必须显式标注为假设并列出验证条件 | 预测、估算、单一来源消息 |

硬性规则：
1. 每个数据点格式：`数值 [事实·L1｜报告期｜来源]`，缺来源不得作为事实。
2. 每个关键结论（买卖/评级/目标价类）必须同时给出**支持证据与反对证据**，只有单方证据的结论降级为 L3。
3. 季度、年度、滚动（TTM）口径必须分开标注，禁止混入同一对比。
4. `validator.py` 在报告生成时扫描：无证据标签、无来源、无反证的结论一律拦截或降级，并在日志列出；无法通过校验时宁可不输出该结论。

## 二、事件催化剂双分级
**事件证据分级（可信度）：**
- L1 正式公告：交易所公告、政府部门文件、公司公告；
- L2 权威报道：主流财经媒体、行业机构数据、券商研报（标注机构）；
- L3 市场传闻：社媒消息、未署名爆料、"据悉/网传"类内容。

**标的受益分级（相关度）：**
- A 直接受益：公司已披露订单/产能/客户/业务收入，附公告来源；
- B 间接受益：业务链条相关但无直接披露，需说明传导路径（L2 推断）；
- C 概念沾边：仅有概念标签或互动平台表态，无实质业务证据。

决策隔离规则：
1. L3 传闻只进入"市场雷达/待核实"区，**禁止生成买卖建议与条件单**；
2. C 类概念公司禁止进入推荐与选股结果，B 类只能列入观察并标注推断；
3. 事件分析必须沿"政策/事件 → 产业链环节 → 具体公司"传导链输出，每一环标注证据等级；
4. 已披露的 A 类公司必须给出披露内容、规模/指标、来源（公告日期），框架协议与当期确认收入需注明口径区别。

## 关键代码模式
```python
@dataclass
class Claim:
    text: str
    level: int                    # 1/2/3
    period: str = ""              # 报告期
    source: str = ""              # 来源
    pro_evidence: list = field(default_factory=list)
    con_evidence: list = field(default_factory=list)
    verify_condition: str = ""    # L3 必填：如何验证

class EvidenceValidator:
    def validate_report(self, sections) -> list:
        """返回违规结论清单（无标签/无来源/无反证/口径混用），拦截输出"""

class CatalystGrader:
    def grade_event(self, event) -> dict:
        """事件等级 L1/L2/L3 + 产业链传导 + 公司分级 A/B/C（附来源）"""
```

## 接线点
- 先改造盘后报告的**一个区块**作为样板，人工确认标签样式与颗粒度后，再推广到全部报告与邮件。
- `news_monitor.py` / `event_calendar.py` 的输出接入 CatalystGrader，未分级事件不进入报告正文。
- 标签样式统一在 evidence_tags.py 渲染（HTML 与纯文本两版），不散落硬编码。

## 实施原则
1. **样板先行**：先一个区块、再全面推广，避免一次性改完全部报告后风格不可控。
2. **静默降级**：取不到来源的数据自动隐藏或降级为 L3，禁止编造来源。
3. **只规范表达、不改变策略逻辑**：不调整任何买卖阈值，仅为结论附加证据结构。
4. 证据标签在邮件 HTML、企业微信文本、dashboard 中均需正确显示。
